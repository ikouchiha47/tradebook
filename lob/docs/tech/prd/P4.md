# P4 — Backtest (replay → strategy → verdict)

Goal: run the market maker (P3) against **replayed historical ITCH** through the engine, and
report fills, P&L, inventory, latency, and adverse selection. This is the stage that turns the
system into a *result* — the quant-side artifact.

## The one design choice that matters: the fill model

```
(a) trade against the historical book   the strategy's orders are matched against the
                                        replayed book; filled if the tape crosses the price,
                                        partial by historical size. Simple, standard.
                                        Optimistic: ignores queue position + market impact.

(b) run your own engine                 the strategy trades on your matching engine; the tape
                                        seeds/crosses it. More complete, much harder to make
                                        realistic (you must model how the tape interacts
                                        with your resting orders).
```
Pick **(a) for v1** and say so in the README — a backtest's honesty is the point.

## Scope

In:
- replay ITCH (P1 feed) → book;
- drive the strategy from book updates;
- **fill model (a)**: a resting quote fills when the tape crosses it; partial by size;
- **metrics**: P&L, inventory over time, fill count/rate, spread captured, latency histogram,
  **adverse selection** (mid move after each fill — the market maker's real cost);
- a report (stdout table + summary).

Out: multi-asset, market impact, queue-position realism, fees beyond a flat rate.

## Tasks (each with Done)

- T0 replay harness — `feed → book → strategy` tick loop. Done: runs end to end on a slice.
- T1 fill model — crossing ⇒ fill at the touch, partial by historical size. Done: fixtures
  with known crossings fill as expected.
- T2 P&L + inventory — mark-to-mid, P&L attribution. Done: numbers that tie to the fills.
- T3 latency + adverse selection — fill→mid-move histogram; per-fill adverse move. Done:
  a distribution printed.
- T4 report — a summary table + a one-line method note. Done: `make backtest`.
- T5 baseline sanity — a trivial "always cross" strategy to validate the harness end to end.
  Done: the baseline's P&L is explainable by hand.

## Definition of done

`make backtest` replays a day of ITCH, runs the market maker, and prints P&L, inventory, fill
rate, a latency histogram and an adverse-selection number — with the fill-model assumptions
stated up front. That's the portfolio artifact: an engine, a trader, and an honest verdict.
