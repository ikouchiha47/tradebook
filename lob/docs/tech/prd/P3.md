# P3 — Market maker

Goal: a market-making strategy that quotes **both sides** of one symbol on the engine, manages
inventory, and reacts to fills. In-process, driven by book updates and fills — no I/O. This is
the market-microstructure stage, and the strongest HFT-interview talking point.

## Scope

In:
- strategy interface: `on_book(snapshot|update)`, `on_fill(fill)`; submit/cancel via the engine;
- **fair price**: mid, then **microprice** (size-weighted: `(bid*ask_sz + ask*bid_sz)/(bid_sz+ask_sz)`);
- **quoting**: `bid = fair − half_spread − skew`, `ask = fair + half_spread − skew`, size per side;
- **inventory skew**: shift quotes against the position so it mean-reverts (long ⇒ quote lower);
- **volatility scaling**: widen spread / shrink size when the mid moves;
- **risk**: max position, max loss, max open orders, a halt switch.

Out: alpha signals, multi-symbol, real connectivity, exchange-grade fee/rebate modelling.

## Model

```
FairPrice  = mid | microprice
Quote      = fair ∓ (half_spread + vol_adj) − skew(inventory)
Risk       = { max_pos, max_loss, max_open }  -> halt when breached
```

## Tasks (each with Done)

- T0 strategy interface — a no-op strat wired to the engine (submits nothing).
  Done: engine drives `on_book`/`on_fill`; build + tests green.
- T1 fair price — mid, then microprice. Done: unit tests on hand-built books.
- T2 symmetric quoting — fixed spread/size both sides. Done: quotes track the mid.
- T3 inventory skew + position limits. Done: position stays within `max_pos`; quotes skew.
- T4 volatility-scaled spread/size. Done: spread widens as realised vol rises.
- T5 risk halts — max pos/loss/open → stop quoting. Done: breach flips to flat + halt.
- T6 tests + bench — invariants (never quote *through* the book; respect limits) + ns/quote.
  Done: `make test` green; a quote-cycle ns number.

## Definition of done

Quotes one symbol continuously, skews on inventory, widens on volatility, halts on risk limits,
and every quote is defensible (never crosses the book, never exceeds limits).
